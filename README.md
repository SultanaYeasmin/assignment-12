# 📦 Transito – Parcel Management System  

An online platform where users can **book parcels for delivery**, **admins manage and assign delivery men**, and **delivery men complete deliveries**.  
This project is built with the **MERN stack (MongoDB, Express.js, React.js, Node.js)** and follows all assignment requirements.  

---

## 🌐 Live Website  
🔗 [Transito Parcel Management System](https://parcel-management-website.web.app)  

---


## ✨ Features  

1. **Authentication & Authorization**  
   - Email/Password login & registration  
   - Social login (Google)  
   - Role-based authentication (User, Delivery Man, Admin)  

2. **Responsive Design**  
   - Fully responsive for **mobile, tablet, and desktop**  
   - Responsive dashboard with sidebar  

3. **User Dashboard**  
   - Book parcels with full details  
   - Auto-calculated parcel price (based on weight)  
   - Manage My Parcels (update, cancel, review, pay)  
   - Profile management with image upload  

4. **Admin Dashboard**  
   - View & manage all parcels (assign delivery men, update status)  
   - Manage all users (promote to Delivery Man or Admin)  
   - Manage all delivery men (see performance & reviews)  
   - Admin statistics page with **React Apex Charts**  
   - Date range filter for parcel management  

5. **Delivery Man Dashboard**  
   - View assigned deliveries only  
   - Update status (delivered, canceled)  
   - See parcel location on **map modal** (Leaflet/MapBox)  
   - View received reviews  

6. **Top Delivery Men Section**  
   - Displays top 3 delivery men based on delivered parcels & ratings  

7. **Homepage Features**  
   - Stunning banner with search bar  
   - Features section (Parcel Safety, Fast Delivery, Tracking, etc.)  
   - Statistics with **animated counters (react-countup)**  

8. **Payment Integration**  
   - Stripe checkout system for parcel payment  
   - Payment success page with **confetti animation** 🎉  

9. **Notifications**  
   - SweetAlert/Toast notifications for all CRUD operations  
   - No default browser alerts  

10. **Other Technical Features**  
    - Environment variables for security (Firebase, MongoDB)  
    - Data fetching with **TanStack Query**  
    - MongoDB Aggregation for Admin statistics  
    - Pagination for All Users table  
    - Dark/Light theme toggle (optional)  

---

## 🛠️ Tech Stack  

- **Frontend:** React.js, Tailwind CSS, ShadCN UI, DaisyUI  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose ORM)  
- **Authentication:** Firebase Auth  
- **State Management:** TanStack Query  
- **Charts:** React ApexCharts  
- **Maps:** React Leaflet / MapBox  
- **Payment:** Stripe
